# Homebrew tap for Envelope

This tap packages [Envelope](https://github.com/tymrtn/U1F4E7) (`U+1F4E7`), a BYO mailbox email client with agent-native primitives.

The installed binary is `envelope`.

## How do I install these formulae?

```bash
brew install tymrtn/u1f4e7/envelope
```

The previous formula name still works and installs the same package:

```bash
brew install tymrtn/u1f4e7/u1f4e7
```

Or `brew tap tymrtn/u1f4e7` and then `brew install envelope`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tymrtn/u1f4e7"
brew "envelope"
```
